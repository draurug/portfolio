Ethereum Fraud Detection

Course paper · Machine learning

Binary classification of Ethereum addresses from 50 transaction-derived features. LightGBM reaches F1 0.987 on held-out data. That number only meant something after I found the leak behind it: a naive random split was putting 5.7% of the test set into training through duplicate feature profiles.

Voronoi Path Planner

Course project · Computational geometry

A path planner for a robot with physical width, where clearance matters more than distance. It builds a clearance field and binary-searches the largest clearance that still connects start to goal. Dijkstra then runs inside that corridor.
